# Font files cần thả vào đây

Đặt đúng các tên file sau (định dạng `.woff2`) để `@font-face` trong `src/index.css` nhận diện tự động — không cần sửa code:

- `SacViet-Regular.woff2`
- `SacViet-Bold.woff2`
- `SVNGilroy-Regular.woff2`
- `SVNGilroy-Semibold.woff2`
- `SVNGilroy-Bold.woff2`

Nếu tên file gốc khác, đổi tên lại cho khớp danh sách trên, hoặc báo lại để cập nhật `src/index.css`.
